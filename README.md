# Distribuidora San Pablo S.A.

Base inicial del proyecto web para gestion comercial, cotizaciones, inventario y futura facturacion electronica en Chile.

## Alcance inicial

- dashboard comercial
- clientes
- proveedores
- catalogo mixto
- cotizaciones
- ordenes de trabajo
- compras
- entregas
- inventario
- cobranzas
- reportes
- preparacion del modulo de facturacion

## Stack

- `Next.js`
- `TypeScript`
- `Appwrite`
- despliegue frontend en `Vercel`

## Levantar en local

1. Instalar dependencias:

   ```bash
   npm install
   ```

2. Ejecutar desarrollo:

   ```bash
   npm run dev
   ```
